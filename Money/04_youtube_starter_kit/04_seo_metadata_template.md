# SEO Metadata Template

A great video with bad metadata gets buried. This template generates everything you need for the upload page.

## The master metadata prompt

```
Act as a YouTube SEO specialist.

Write complete metadata for this video:

Topic: [TOPIC]
Niche: [NICHE]
Script summary: [2-3 SENTENCE SUMMARY]
Target keyword: [PRIMARY KEYWORD]

Output:

1. TITLE (under 60 characters)
   - Includes main keyword
   - Triggers curiosity
   - Has a specific number where possible

2. DESCRIPTION (200 words)
   - First 2 sentences: hook + keyword (these show in search)
   - Then: bulleted key takeaways
   - Then: timestamps for chapters
   - Then: 3 affiliate/link slots (label as [LINK 1], [LINK 2], [LINK 3])
   - Then: CTA to subscribe
   - Then: hashtags (3 max)

3. TAGS (15 total, mix of broad and specific)
   - 5 broad niche tags (high volume, high competition)
   - 5 specific topic tags (medium volume, medium competition)
   - 5 long-tail tags (low volume, low competition)

4. CHAPTER TIMESTAMPS (5 chapters)
   - First chapter at 0:00 (called "[topic intro]" or similar)
   - Each chapter under 6 words

5. PINNED COMMENT (3 options)
   - Each option boosts engagement differently:
     - Option A: question to drive replies
     - Option B: controversial take to drive debate
     - Option C: bonus value (something you forgot to add to the video)

Optimize for: click-through rate AND watch time.
```

## Upload checklist

- [ ] Title written, under 60 characters
- [ ] Description has keyword in first sentence
- [ ] Description has 5 chapter timestamps
- [ ] Description has 3 link slots filled (affiliate, channel, etc.)
- [ ] 15 tags entered
- [ ] Thumbnail uploaded
- [ ] End screen set up (subscribe + next video)
- [ ] Cards added at key moments
- [ ] Visibility set to Public (NOT scheduled if you want to test publish-day algorithm push)
- [ ] Comments enabled
- [ ] First comment pinned (your engagement bait)
- [ ] Video added to a playlist (helps session time)

## After publishing (first 60 minutes)

- Share to one personal channel (Twitter/X, LinkedIn, Discord) — drive 10-20 outside views
- Reply to first 5 comments within 60 min — boosts engagement signal
- Check thumbnail rendering on mobile (most viewers are mobile)
- Don't check views obsessively for the first 24 hours — the algorithm needs time
