# Script Template — Hook → Stakes → Payoff → CTA

The single most important video element is the first 30 seconds. Bad hook = no views, no matter how good the rest is.

## The master script prompt

```
You are a senior YouTube scriptwriter for faceless educational channels.

Write a full script for this video:

Topic: [TOPIC]
Target audience: [AUDIENCE FROM CHANNEL IDENTITY]
Video length: [5 / 8 / 12 minutes]
Tone: [educational / storytelling / list-based]
Channel niche: [NICHE]
Channel voice: [PASTE FROM CHANNEL IDENTITY]

Script requirements:
- Hook: first 30 seconds must create a pattern interrupt
- NO intro ("Hey guys welcome back")
- Use the open loop technique: tease the payoff early
- Write in spoken English, not essay English (use contractions)
- Include [PAUSE] markers for natural delivery
- Include [VISUAL: description] tags for every scene
- End with a SOFT CTA that doesn't sound like begging

Output:
- Full word-for-word script
- Estimated runtime
- 5 thumbnail concept ideas
- 3 title variations (one curiosity, one SEO, one emotional)
```

## The structure breakdown

### 1. The Hook (first 30 seconds)
This decides whether the algorithm pushes or buries the video.

**Bad hook:** "Hey guys, welcome back to the channel. Today we're going to talk about..."

**Good hook patterns:**
- **Pattern interrupt:** Start mid-action ("I just made $4,000 in 12 minutes")
- **Curiosity gap:** State the result, hide the method ("This $40 setup replaces a $4,000 studio")
- **Status shift:** "Six months ago I was [low status]. Today I'm [high status]."
- **Unresolved loop:** "There's one thing 99% of people miss about [topic]. By minute 7 you'll know what it is."

### 2. The Stakes (seconds 30-60)
Why does the viewer care? What's at risk if they don't watch?

- Personal: "If you skip this, you'll waste $X / weeks of time"
- Competitive: "Everyone else in your industry already knows this"
- Time-sensitive: "This window closes in [timeframe]"

### 3. The Body / Escalating Stakes (the middle 60-70% of the video)
- One main argument per section
- Each section delivers a specific payoff
- Use the open loops you set up earlier
- Specific numbers, named examples, real stories
- Pattern interrupts every 60-90 seconds (B-roll change, music shift, visual joke)

### 4. The Payoff (the actual answer/insight)
The thing you teased in the hook. Deliver it clearly. No hedging.

### 5. The CTA (last 30 seconds)
- Soft, not begging
- Tease the next video (binge loop)
- One clear action ("If you want the template, link in description")
- NEVER say "smash that like button"

## Quality bar (check before recording voiceover)

- [ ] Hook works as a 6-second TikTok if you cut it out
- [ ] Every section has a specific number or named example
- [ ] No "let's dive in", "in this video", "stay tuned"
- [ ] Words spoken aloud sound natural (read it out loud — if it's awkward, rewrite)
- [ ] CTA isn't begging
