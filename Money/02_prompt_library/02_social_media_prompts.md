# Social Media Prompts

## 1. Social Media Strategy Architect
```
Act as an expert social media manager. Analyze my business, niche, audience, competitors, and goals. Create a growth-focused social media strategy with:
- content ideas (10)
- positioning statement
- branding direction
- audience engagement tactics
- the platforms to prioritize and why

My business: [DESCRIBE]
My niche: [NICHE]
My audience: [AUDIENCE]
My goal: [GOAL]
```

## 2. Content Pillar Builder
```
Create 5 strong content pillars for my social media brand based on my niche and expertise. For each pillar:
- 5 post ideas
- what they educate, entertain, or inspire about
- the format that works best (carousel, reel, thread, etc.)

Niche: [NICHE]
Expertise: [EXPERTISE]
```

## 3. 30-Day Content Calendar
```
Create a 30-day social media content calendar for my niche. For each day include:
- post idea
- recommended format (carousel, reel, thread, etc.)
- the goal of each post (awareness, engagement, lead generation)
- one engagement question to ask in caption

Niche: [NICHE]
```

## 4. Scroll-Stopping Post Creator
```
Create a highly engaging social media post about: [TOPIC]
- Start with a strong hook that stops scrolling
- Deliver clear value in simple language
- End with a CTA encouraging comments or shares
- Length: [PLATFORM-APPROPRIATE]
- Voice: [DESCRIBE]
```

## 5. Viral Short-Form Script
```
Write a short-form video script for Instagram Reels, YouTube Shorts, or TikTok about: [TOPIC]
Structure:
- Curiosity-driven hook (first 3 seconds)
- Quick value delivery (3–25 seconds)
- Pattern interrupt at 15 seconds
- CTA in last 5 seconds
Target length: 30 seconds spoken, 45 seconds with B-roll.
```

## 6. Engagement & Community Builder
```
Create a strategy to increase engagement on my social media posts. Include:
- 10 conversation starters
- 5 comment prompts to use in captions
- storytelling techniques specific to my niche
- community-building tactics that encourage repeat interaction
- how often to post and when

Niche: [NICHE]
Current follower count: [NUMBER]
```

## 7. Performance Optimization
```
Review my social media strategy and recent posts. Identify:
- what content performs best (pattern across top 5)
- what needs improvement (pattern across bottom 5)
- specific changes to increase reach
- specific changes to increase engagement
- specific changes to increase conversions to [GOAL]

Paste recent post performance here: [DATA]
```
