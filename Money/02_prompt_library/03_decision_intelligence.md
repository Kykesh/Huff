# Decision Intelligence Prompts — 7 Frameworks

Seven prompts that access mental models consultants charge $500/hour to apply.

## 1. First Principles Thinking
```
I'm dealing with a problem and I want you to help me think through it using First Principles Thinking.

Don't give me advice based on convention or what's normally done. Instead, break my problem down to its most fundamental truths, the things I know are true without question. Then build the solution back up from there.

Ask me Socratic questions to challenge every assumption I'm holding about why the situation is the way it is.

My problem: [DESCRIBE]
```

## 2. Inversion
```
I want you to help me solve a problem using Inversion, the mental model popularized by Charlie Munger.

Instead of asking "How do I succeed at this?", start by asking "How would I guarantee failure at this?"

List every way this could fail, every behavior that would sabotage success, every blind spot that would compound into disaster. Then we'll work backward from those failures to identify what I must avoid at all costs.

My situation: [DESCRIBE]
```

## 3. The 5 Whys
```
I have a recurring problem and I need to find the actual root cause, not just the surface symptom. Use the 5 Whys method from the Toyota Production System.

Start with the problem I describe. Ask "Why does this happen?" Then take my answer and ask "Why?" Continue 5 levels deep.

After we reach the root cause, give me one specific, structural change I could make to address it — not a behavior change, but a system change.

My problem: [DESCRIBE]
```

## 4. Second-Order Thinking
```
I'm about to make a decision and I want you to help me think through it using Second-Order Thinking, as described by Howard Marks.

Most people only think about the immediate result of a decision. Map out the consequences in three levels:
- 1st-order: what happens immediately
- 2nd-order: what happens next as a result of the 1st order
- 3rd-order: what happens as a downstream consequence of the 2nd order

For each level, ask: "And then what?" Identify which 3rd-order consequence is most likely to derail this decision.

My decision: [DESCRIBE]
```

## 5. Regret Minimization Framework
```
I'm stuck on a major life or career decision. Help me think through it using Jeff Bezos's Regret Minimization Framework.

Ask me to imagine myself at 80 years old looking back on this moment. From that vantage point, help me evaluate:
- Which path would I regret NOT taking?
- Which path would I be proud of taking, even if it failed?
- Which path am I drawn to for the wrong reasons (status, fear, others' approval)?
- Which path most aligns with the person I want to have been?

My decision: [DESCRIBE]
```

## 6. Opportunity Cost Analysis
```
I want you to help me evaluate a commitment using Opportunity Cost Analysis.

Every time I say yes to something, I'm saying no to everything else I could do with that time, money, or energy. I need you to make those invisible tradeoffs visible.

For this commitment, identify:
- The 3 highest-value things I'm implicitly saying no to
- The hidden costs (time, energy, attention) I'm not counting
- The compounding cost over 6 months / 1 year / 3 years
- Whether the expected payoff justifies the opportunity cost

My commitment: [DESCRIBE]
What it costs me: [TIME / MONEY / ENERGY]
```

## 7. Pre-Mortem Analysis
```
I'm about to start a project and I want you to run a Pre-Mortem Analysis on it, based on psychologist Gary Klein's method.

Here's how it works: Imagine it's 6 months from now and this project has failed completely. It's dead. Now work backwards.
- What were the 5 most likely reasons it failed?
- Which failure mode was foreseeable from where I am today?
- For each, what's the early warning sign I should watch for?
- For each, what's the structural change I can make NOW to prevent it?

My project: [DESCRIBE]
Timeline: [DURATION]
Resources: [WHAT YOU HAVE]
```
