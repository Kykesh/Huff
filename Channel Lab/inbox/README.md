# Inbox — Drop Zone

Found a channel worth studying? A niche idea at 2 AM? Drop it here — any format, zero polish:

- a `.md` or `.txt` file with a YouTube link
- one line: "saw a guy doing castle history with maps, 800K subs, check it"
- a list of three ideas in one file

Then, whenever: **`/scout inbox`** — every note gets a full evaluation in `evaluations/` and the processed note gets deleted from here.

Don't organize this folder. Don't agonize. When in doubt, inbox.
